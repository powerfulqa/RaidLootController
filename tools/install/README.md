# One-click install

1. Windows: download [Install-RaidLootController.bat](https://github.com/powerfulqa/RaidLootController/releases/latest/download/Install-RaidLootController.bat) and double-click it.
2. If Windows asks "Are you sure you want to run this software?", click **Run**. If the browser warns about the file, choose **Keep**. If Windows needs permission to write to the game folder, the installer says so: press Enter, then **Yes**.
3. It finds WoW: Forever, puts the addon in its `Interface\AddOns` folder and shows the version. If it can't find the game, paste the folder Battle.net opens from the gear menu > **Show in Explorer**.
4. Mac or Linux: download [install-raidlootcontroller.command](https://github.com/powerfulqa/RaidLootController/releases/latest/download/install-raidlootcontroller.command), open Terminal and run `bash ~/Downloads/install-raidlootcontroller.command`.
5. To update, run the same file again. Your settings and loot history are kept.
6. If the game is open, type `/reload` in chat afterwards.
